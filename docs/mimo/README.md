# Mimo : wireframes et dimensions

[Ouvrir ou télécharger le blueprint PDF en français](notchy-mimo-wireframe.pdf)

Ce document de 24 pages rassemble les tailles d’encoche, les formats de modules, les placements de Mimo, ses huit variantes, ses états, ses émotes et des séquences d’animation. Les poses proviennent du moteur Canvas de Notchy. Les cotes distinguent les pixels de conception, les dimensions affichées après l’échelle de l’app et les pixels physiques de Windows.
