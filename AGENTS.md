# Mémoire et stockage Notchy

Lire et appliquer `../AGENTS.md`, puis `../Notchy — Mémoire/Accueil.md` avant une tâche. Le coffre conserve les décisions, preuves et points ouverts. S’il n’est pas accessible, le signaler ; ne pas inventer son contenu.

Ne jamais exécuter de purge sans nouvel accord humain sur les chemins exacts. `npm run storage:check` est un bilan ; `npm run storage:guard` peut bloquer de nouveaux builds, mais ne supprime rien. Préserver les sources, maquettes, données, dernier essai, dernier installateur et retour arrière jusqu’à validation.
